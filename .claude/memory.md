# Reusable project lessons

- On Windows, a fixed pytest `--basetemp=.pytest_tmp` can become undeletable after an interrupted or sandboxed run. If setup errors report `WinError 5`, rerun with a fresh, uniquely named basetemp inside the workspace before treating failures or coverage drops as product defects.
- Before release/tagging, run the same `ruff check .` command used by CI; passing pytest and package builds does not imply the CI matrix will proceed past lint.
- Caches for option-sensitive remote checks (for example stable-only versus prerelease updates) must include the option in the cache key or cached payload validation.
- When adding an error field to a library result, also test the CLI exit code for that error path; displaying an error message while returning success still breaks CI callers.
- After decoding cache JSON, validate that the root value is a mapping and that required values have usable types before calling mapping methods or doing arithmetic.
- On Windows, isolated `python -m build` may fail while logging localized pip output with `UnicodeDecodeError`; retry with `PYTHONUTF8=1`, `PYTHONIOENCODING=utf-8`, and `python -m build --no-isolation` to verify packaging before treating it as a project build defect.
- When bumping MathFmt's current version for a release, update self-update tests so fake "newer release" fixtures are greater than the new current version; otherwise update detection tests will correctly report no update.
- When a scan report distinguishes original `source` from parser-ready `linear`, update apply, validate, and cross-backend checks to parse `linear`; otherwise features such as delimiter stripping can convert successfully but fail validation.
- When one reviewed formula can contain multiple parse units, split it consistently in scan, apply, validation, and cross-backend checks; keep coverage counts candidate-based, then assemble the final layout only during apply.
- Use the exact skill locator shown in the available-skills catalog; plugin cache families such as `openai-curated-remote` and `openai-bundled` are not interchangeable.
- When a grammar keyword separates two expressions (for example `if` in cases syntax), tokenize it before the generic identifier rule; otherwise implicit multiplication can consume it and make branch-level errors impossible to diagnose.
- If an explicit formula delimiter appears inside text that otherwise resembles code, scan only the explicit spans instead of disabling code exclusion for the whole paragraph.
- After replacing an inline DOCX formula, set `xml:space="preserve"` on any surviving `w:t` whose text starts or ends with a space; XML text checks can pass while Word/LibreOffice still collapses the visible boundary space.
- On Windows, if the Documents renderer hangs after selecting LibreOffice, call `C:\Program Files\LibreOffice\program\soffice.com` directly with a unique `-env:UserInstallation=file:///...` profile, then rasterize the PDF. The bundled `pdftoppm.cmd` wrapper may point at a stale path; the working executable is under `dependencies/native/poppler/Library/bin/pdftoppm.exe`.
- If GitHub CLI authentication is invalid and the connector/public API fallbacks also fail, use a read-only in-app browser tab to capture public Issue acceptance criteria; do not use that browser fallback for GitHub writes.
- When a DOCX render fixture is assembled from minimal OOXML, include `w:sectPr` with `w:pgSz` and `w:pgMar`; the Documents renderer cannot calculate DPI without section properties.
- Render adjacent `bra(...) ket(...)` as one bra-ket structure, not two concatenated half-delimiters; visual QA exposes the otherwise valid but misleading double-bar result.
- In a sandboxed Windows shell, `gh auth status` can report a keyring token as invalid because Windows Credential Manager is inaccessible; rerun GitHub CLI checks and writes in the approved system-permission context before asking the user to authenticate again.
- If the GitHub app returns `403 Resource not accessible by integration` when creating a PR, fall back to authenticated `gh pr create --draft` with the Markdown body stored in a real newline-preserving temp file.
- Targeted pytest runs inherit the repository-wide coverage threshold and may exit nonzero even when every selected test passes; use the full suite for release validation or override pytest addopts only for focused diagnostics, and do not misclassify subset coverage as a product failure.
- When auditing CI/release configuration, enumerate `.github/workflows` before assuming a conventional filename such as `release.yml`; this repository uses `publish.yml`. For Windows Unicode/XML diagnostic snippets, set `PYTHONIOENCODING=utf-8` and prefer a PowerShell here-string over heavily escaped `python -c` code.
- A literal `&` inside an OMML `m:eqArr` acts as a Word alignment marker but renders visibly in LibreOffice. For cross-application relation alignment, use a two-column native `m:m` with a right-justified left column and left-justified relation column; keep `m:eqArr` only as the no-common-relation fallback.
- Before Word COM render QA, record existing `WINWORD.EXE` instances. If an `/Automation -Embedding` instance times out, identify it by creation time and stop only that PID so an existing user Word session is preserved.
- Offline wheel installs can still trigger pip's network version check; set `PIP_DISABLE_PIP_VERSION_CHECK=1`. The bundled Poppler runtime may include `pdftoppm` and `pdfinfo` but not `pdftotext`; use bundled `pypdf` for PDF text assertions when `pdftotext` is unavailable.
- GitHub Actions can leave a job `queued` with no steps and `runner_id=null`, then cancel it after about 15 minutes. Before retrying a release, verify the build never ran and every publish/release dependency was skipped; only then dispatch the exact tag again to avoid duplicate uploads.
- When `gh run view` intermittently fails with `EOF` or Schannel/TLS errors, query the exact run through the GitHub connector or the direct `gh api .../actions/runs/{id}/jobs` endpoint. Do not infer failure or create a duplicate run from a monitoring transport error.
- A tag pushed by an automation credential may not emit a new Actions run. Keep `workflow_dispatch` available, list recent publish runs to confirm no matching run exists, and manually dispatch the immutable tag once.
- After publishing, download the exact version from PyPI with cache disabled and compare its SHA-256 with the GitHub Release asset digest; a match verifies both registries received the same wheel.
- In this Windows workspace, `python` on `PATH` may resolve to the agent-reach virtual environment without project test dependencies. Confirm the interpreter first, then use the system Python with a per-process `PYTHONPATH=src` for the src-layout test suite.
- WPS Writer can discard a trailing ordinary space in an OMML text run even when `xml:space="preserve"` is present. For a required visible boundary such as a cases label followed by a math atom, use a non-breaking space and verify the round trip through WPS PDF output.
- WPS Writer round-trip QA can be automated safely through `KWps.Application`: record existing WPS PIDs, keep the application hidden, release COM objects, wait briefly for natural exit, and never terminate pre-existing user processes.
- Setuptools source distributions do not automatically include arbitrary documentation or PowerShell QA scripts. Add explicit `MANIFEST.in` entries and inspect the rebuilt archive before declaring packaging complete.
- In Windows PowerShell, load `System.IO.Compression.FileSystem` before using `System.IO.Compression.ZipFile` to inspect wheel metadata. When release artifacts were created by an approved out-of-sandbox build, read and hash them in the same approved context to avoid misleading access-denied errors.
- For large DOCX workflows, group candidates by OOXML part and parse/serialize each part once. Reparsing a growing document for every paragraph or review candidate approaches quadratic time; cache paragraph text per part during coverage validation as well.
- When redirecting `tests.acceptance.gen_docs.OUT`, create the replacement directory before calling an individual document factory; only `all_docs()` creates `OUT` automatically. The CLI WPS profile is requested with `validate --compatibility wps` (there is no `--wps` shorthand).
- On Windows, `Get-Command` may resolve bundled `.cmd` wrappers with the executable path in `CommandInfo.Source` while `FullName` is empty; invoke the non-empty resolved property when launching tools such as `pdftoppm`.
- Before publishing GitHub workflow changes, verify referenced action major tags against the official action repositories; in August 2026 `actions/checkout` is v6, `actions/setup-python` is v6, `actions/upload-artifact` is v7, and `actions/download-artifact` is v8.
- When Git's TLS transport fails but authenticated `gh api` works, the Git Database API can reproduce a commit safely: build a candidate tree from LF-normalized committed files, require its tree SHA to match local `HEAD^{tree}`, and create no ref until content is proven. The REST commit endpoint preserves the supplied timezone but may omit the commit message's trailing newline, so compare tree identity rather than assuming `git commit -m` will have the same commit SHA.
- `http.server.BaseHTTPRequestHandler.send_error(code, message=...)` encodes `message` as latin-1 for the HTTP status line and raises `UnicodeEncodeError` on non-ASCII text (e.g. Chinese); pass localized/non-ASCII detail via the `explain=` keyword instead, which is UTF-8-encoded into the response body.
- In this Windows workspace, the installed `ruff.exe` (and other Scripts/*.exe launched as a subprocess, e.g. via `python -m ruff`) can be blocked by a Windows Application Control policy with `OSError: [WinError 4551] 应用程序控制策略已阻止此文件`, unrelated to any product defect. When this happens, `pytest` and plain `python -c` scripts are unaffected — fall back to running pytest for verification and a manual style pass, and tell the user ruff could not be run in-session so they can run `ruff check .` / `ruff format --check .` themselves before release.
- The GUI's browser-only behaviour can be verified without a human: `mathfmt gui --port <n> --no-browser`, then drive it with the `agent-browser` CLI (`open`, `upload "#file-input" <docx>`, `eval <js>`). Two traps found doing it — the page's script is not on `window`, so `eval` cannot call its functions (read the DOM instead), and `click` on a button below the fold can silently no-op, so dispatch `document.getElementById('apply-btn').click()` through `eval` when a click reports success but nothing happens. The first `agent-browser open` after a cold start can take minutes; later calls are fast.
- A `FormulaError` message carries a snippet and a caret line aligned for a monospace terminal. Anywhere it is shown in HTML (the GUI's candidate list and inline edit errors), collapse whitespace first — in a proportional div the caret points at nothing and the line break just makes the message look broken.
